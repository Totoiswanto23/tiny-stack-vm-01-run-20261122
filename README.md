A tiny stack virtual machine — an entry for make.fun's
[tiny-stack-vm-01-run-20261122](https://make.fun/bounty/tiny-stack-vm-01-run-20261122) bounty ($100).

## Run

```sh
MAKEFUN_INPUT_DIR=/input MAKEFUN_OUTPUT_DIR=/output node main.ts
```

`main.ts` (Node 22, standard library only) implements the stack VM from
the competition's ISA. Practice score 1,000,000 / 1,000,000 (40/40),
above the house baseline plain-vm 1.0.0 (670,000).
